# Ayush Chakraborty — Premium Portfolio

This is a zero-build static website. It uses only HTML, CSS and vanilla JavaScript, so it can be hosted free on GitHub Pages, Cloudflare Pages, Netlify or Vercel.

## Included
- Premium editorial homepage
- Full ITC research page
- Animated valuation football field
- Real DCF sensitivity matrix calculated from the FY27–FY31 FCFF model
- Animated segment and forecast visuals
- Embedded 65-observation regression scatterplot
- Research downloads
- Writing, Projects, About and CV pages
- Sticky research contents on desktop
- Scroll progress and active section state
- Mobile menu + mobile research download CTA

## Before publishing
1. LinkedIn is already connected to `https://www.linkedin.com/in/ayushchakr/`.
2. The optimised CV is already included in `downloads/` as PDF and DOCX.
3. After buying your domain, keep `ayushchakraborty.com` in the CV or replace it with the exact domain you purchase.
4. If you later export the ITC research report as PDF, replace the DOCX download with the PDF.
5. Proofread all personal and project details, then preview `index.html` locally.

## Free hosting + custom domain
### GitHub Pages
Upload this folder to a GitHub repository, enable Pages from the `main` branch, then add your domain under Settings → Pages.

### Cloudflare Pages
Connect the GitHub repository to Cloudflare Pages. No build command is required. Add your purchased domain under Custom domains.

No paid website builder is required.
